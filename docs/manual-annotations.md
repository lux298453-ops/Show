# 手动说明标注

选择画板后，在右侧「属性 → 说明标注」点击「添加说明」。可以关联现有元素，也可以选择「整个页面」填写整体功能说明。标题最多 200 字，正文最多 5000 字，支持换行。

保存后说明进入该页面的列表。属性栏、画布说明卡片和说明预览抽屉都采用双击说明打开编辑弹窗，卡片不显示编辑、删除按钮。弹窗可以修改标题和正文，左下角有「删除说明」。删除前确认具体说明，取消不会移除数据；删除只移除说明，不删除元素或交互。画布说明面板的加号也能新增。顶部预览菜单的「说明预览」用于同时查看原型与说明，也可在说明抽屉中添加。

说明标题单独持久化，不再改动关联元素名称；添加、编辑、删除说明都不重建 HTML、不创建交互。人工添加或编辑的说明标记为 `source=user`。重新识别重建元素时，人工说明及原位置保留，转换为页面说明；原关联不自动猜测迁移到新元素。

接口：`POST /api/projects/{id}/pages/{pageId}/annotations`、`PUT /api/projects/{id}/annotations/{annId}`、`DELETE /api/projects/{id}/annotations/{annId}`。后端校验项目、页面和关联元素所属关系。

验证：`AnnotationMysqlIntegrationTest` 使用独立临时项目，覆盖持久化、排序、字段限制、所属校验、说明标题与元素名称独立、删除无副作用，以及重新识别清理时保留人工说明。运行时设置 `-Dwireforge.integration=true`。
