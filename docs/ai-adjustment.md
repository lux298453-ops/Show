# 全屏演示与 AI 调整

演示背景、工具栏、下拉菜单和 AI 面板使用项目主题变量。AI 面板打开时保持工具栏可见；原型文档继续使用自身颜色。

## 会话与版本

- `useAiAdjustment.ts` 按项目和页面管理会话。请求、取消、错误、草稿、消息和版本独立；异步回调始终持有原会话。
- 每个结果记录不可变的完整修改前后 HTML。“应用修改”保存该结果；“保存当前预览”保存当前草稿。历史恢复明确替换本页整个版本。
- 局部调整通过 `aiAdjustment.ts` 在请求时的源文档中定位、校验并替换子树，避免序列化 iframe 注入的运行时。撤回恢复完整源快照，因此支持恢复被删除的元素及其位置。
- 会话和草稿备份到本标签页的 `sessionStorage`，HTML 快照去重；只写入发生变化的页面。刷新或离开时立即刷新备份。关闭标签页后的长期版本归档不在此存储范围内。
- 恢复时如果服务端已更新，保留本地草稿并阻止直接覆盖；用户可丢弃草稿后基于最新画板重新调整。

## 请求与保存契约

- 请求附带最近 12 条消息的需求和摘要，限制为 6,000 字符，不重复传历史完整 HTML。局部请求补充只读父布局与样式，服务端限制为 14,000 字符。
- 后端区分实际修改、无需修改、无效结果。缺失字段、无法解析的 JSON、多根元素、不完整页面不再伪装成成功。
- 校验稳定标识、交互属性、图片地址和外部依赖；明确要求删除或改变交互时允许对应变化。整页语义目标仍由模型判断，结构校验不能替代视觉验收。
- 移动、替换视觉内容时必须保留目标及其保留子元素的稳定标识；只有明确要求删除目标时才移除节点。若模型遗漏某个标识，而其他唯一且未变化的标识能证明原节点仍在，则仅补回遗漏属性。不会按文字、位置猜测对应关系，不会重建缺失节点或覆盖模型明确改名的标识；标识混用、重复和真实丢失仍拒绝。
- 丢失标识的错误指出目标名称与属性，并说明原画板已保留，不再提示用户明确删除正常元素。该修复不自动追加模型请求。
- AI 保存携带 `clientId` 与 `expectedHtml`。服务端检查项目归属、现有编辑锁，并以数据库条件更新校验基线；重复确认同一已保存版本支持幂等返回。普通画布编辑接口仍支持原来的调用方式。
- “停止”取消前端等待并忽略迟到结果；中转站已经受理的生成不保证停止计费。失败保留原请求，可直接重试；基线变化后要求重新发起。
- 输入框和可编辑文字中的撤回快捷键交给输入控件。画板撤回只处理当前预览对应的版本，防止覆盖后续修改。

## AI 调整中的真实图片生成（2026-11-09）

整页和选中元素均支持“重新生成背景图”“重绘角色图片”等指令；也可同时移动文字、修改布局。仅有“移动角色”“背景色改蓝”等需求时不出图。要求使用现有素材时优先使用原 HTML／本项目已保存图片；不会因普通排版修改自动调用图片服务。

1. HTML 模型返回修改方案和最多 3 项 `image_tasks`。任务指定唯一节点的稳定属性和值、图片类型、名称、美术描述及 portrait/landscape/square 构图。
2. 后端先校验整页／片段、编辑标识、交互及全部图片目标。非法、重复、嵌套互相覆盖的目标和 SVG 子节点不调用图片接口；角色容器不能包含按钮或正文。
3. `ProjectArtworkService` 复用本地配置的图片接口，输出真实 PNG。背景提示与角色提示分开，描述不包含界面文字、按钮或水印。当前使用文本出图，不是以原图为输入的图像编辑，不能保证原角色外貌逐像素一致。
4. 成功后只替换目标 img 的 src 或容器背景。响应式 picture/srcset 同步处理，避免旧图覆盖新图；保留稳定标识、布局和交互节点。纯插画容器保留旧 SVG 等备用节点及标识，新增可编辑图片。
5. 返回 `generatedImages` 供对话框展示缩略图；新图立即进入草稿预览，用户点击应用才保存 HTML。撤回恢复旧 HTML 和旧图片 URL。图片文件不覆盖旧版本。

前端为新指令创建 `requestId`，取消、失败、刷新后的重试保留这个 ID。图片缓存按项目、页面、请求、原文档、指令和目标隔离；同请求已完成的图片即使服务重启也复用，新发送的“再生成一次”获得新的图片 URL。部分出图失败不返回半成品 HTML，已成功图片留在缓存供手动重试。服务不自动重复可能已计费的失败调用；供应商受理后失败或用户停止等待仍可能计费。

素材仍存放在设计稿扫描已排除的 `.wireforge-artwork/<项目ID>/`，通过现有受限图片读接口提供。无需修改数据库结构。AI 调整请求的前端等待上限单独设为 30 分钟，不改变普通保存请求；图片服务仍有自己的超时。需要已有 `wireforge.ai.artwork.enabled` 及图片接口配置。

验证使用本地模拟 HTML／图片接口与真实前端组件，不调用收费模型、不修改现有项目。覆盖换图预览、应用、撤回、跨页迟到结果、图片缩略图加载、重试 ID 持久化、图片版本及缓存隔离。浏览器入口 `tests/ai-adjust-preview-harness.html` 的 `resolveImage()` 可模拟出图响应。

本次结果：41 项后端相关测试、前端全量回归、TypeScript 检查和生产构建通过。浏览器验证换图预览、缩略图加载、应用、撤回及跨页草稿隔离；后端更新重启后核对 7 个项目共 274 页 HTML 哈希全部保持不变。

## 保留原文档的局部修改（2026-11-10）

移动提示文字等简单调整不再要求模型复制整页 HTML。优先返回 `edits` 数组，由 `AiAdjustmentEdits` 在原始文档中定位唯一稳定标识，执行样式合并、独立文案更新、受限属性更新或明确要求的删除。最多 32 项；局部元素模式的 `root` 仅指当前片段根，不能访问片段外的节点。修改样式保留其他内联声明，并覆盖既有的高优先级定位样式。

`edits` 可与 `image_tasks` 组合，因此“移动新装扮提示并重新生成背景”只需返回目标属性变化和出图描述。未调整的 SVG、脚本和交互节点从原文档保留，减少模型重抄时混用图标标识的风险。响应仍包含完整调整后 HTML，兼容现有预览、应用及撤回流程。复杂结构调整继续支持 `modified_html`／`modified_snippet`，不能与 `edits` 同时返回。

局部修改不允许改写稳定标识、class、事件处理器及脚本依赖，不允许把包含图标或子控件的容器替换成纯文字。修改方案仍经过原有标识、交互、图片和依赖校验；图片目标先校验再出图。失败保留原画板，不自动追加模型回修请求。

验证：55 项后端相关回归、16 项前端 AI 调整测试通过。额外用实际 115,188 字符家园页和截图中的同一句指令进行一次真实 HTML 模型验证：模型返回 904 字符方案、1 项局部修改和 1 项出图任务，28 个 SVG、脚本和导航保持不变。该次图片接口使用模拟返回，仅验证方案与应用链路，未真实出图、未保存项目。可选入口 `AiAdjustmentPlanningLiveTest` 默认跳过，显式设置 `wireforge.live-adjustment-plan=true` 才调用真实 HTML 模型。

已打包并重启本地后端，核对 7 个项目共 274 页 HTML 哈希全部保持不变；前端与匿名项目读取正常。部署记录保存在本次 `ai-adjust-svg-20261110/restart-result.json`。

## 独立 SVG 插画换图（2026-11-10）

项目 180／页面 2464 的家园背景是 `svg[data-wf-id=sunlit-room-illustration]`，而之前使用项目 182／页面 2503 同名页验证时，其背景为 HTML 容器。旧图片目标校验一律排除 SVG，导致模型选择正确背景后仍报“图片目标不是独立的图片区域”。这属于服务能力缺口；之前一次同名页验证没有覆盖此结构。

独立 SVG 根现在可作为背景、角色、插画或商品的换图目标。根节点须有有效 viewBox 或明确宽高，不能含界面文字、按钮、链接、foreignObject 或交互处理器。保留根节点的所有属性、位置和尺寸，保留备用图形及其标识，仅隐藏旧绘制节点，在原 viewBox 中加入真实 PNG 的 SVG `image`。再次生成时更新同一个受管 image，不累积图层。内部 g/path/defs 等节点仍拒绝，所有任务仍先校验再调用图片服务。

图片请求前给模型补充由同一套校验规则生成的可用目标清单，包含稳定属性、标识、节点类型、说明和支持的图片类型，减少猜测目标。普通文案修改的图片保护校验同时覆盖 SVG image 的 href／xlink:href。前端既有图片显示与安全清洗支持 SVG image，无需放宽脚本或链接权限。

验证：61 项后端回归与 22 项前端 AI 调整／安全测试通过。默认跳过的 `AiAdjustmentSvgBackgroundLiveTest` 显式开启后，使用实际页面 2464 和报错原句调用一次真实 HTML 模型和真实图片服务，生成 934×1684 PNG，原背景之外的 24 个 SVG、所有按钮和脚本不变；结果仅写草稿验证文件及图片缓存，未保存项目页面。`tests/ai-adjust-svg-harness.html` 读取这组真实输入／结果，使用真实演示组件、模拟保存接口，在浏览器验证新背景、缩略图、应用、撤回与原画面恢复。该 harness 的 prototype 接口返回独立副本，避免模拟服务端对象与前端响应式对象共享引用。

本地后端已打包重启，7 个项目共 274 页 HTML 哈希全部保持不变。部署和浏览器结果分别记录在本次 `ai-adjust-background-20261110/restart-result.json` 与 `browser-result.json`，隔离验证服务及窗口已关闭。
